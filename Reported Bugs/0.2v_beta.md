# FruityTech Studio — Beta Demo Bug Reports

## BUG-001 — Save button does nothing (no save UI / no file output)
**Component:** UI (Save/Load)  
**Version:** Beta Demo Build/src code  
**OS:** All  

**Overview:** Clicking **Save** has no visible effect and does not save a project/loop.

**Steps to Reproduce:**
1. Launch FruityTech Studio.
2. Create a loop by placing multiple notes/blocks.

**Expected Results:**

Nothing happens (no UI feedback, no file created).

## BUG-009 — Note labels are musically incorrect (“s” confusing)
**Component:** UI / Note Labeling + Pitch Mapping  
**Version:** Beta Demo Build/src code
**OS:** All  

**Overview:** Tester created a chromatic scale and reports correct pitch progression, but **labels are wrong**: sharp notes appear below their natural counterparts.For example: label ‘As’ should swap order with ‘A’.  
Also sharp notes labeled with ‘s’ instead of ‘#’ is confusing.   
Another tester found note ordering confusing and suggests octave context. 

**Steps to Reproduce:**
1. Launch app.
2. Place notes in ascending chromatic order across all 12 rows.
3. Play back and compare labels to standard chromatic scale.

**Expected Results:**  
Labels match standard order (C, C#, D, D#, E, F, F#, G, G#, A, A#, B) and formatting (#).

**Actual Results:**  
Labels for sharps/naturals appear swapped or ordered incorrectly; “s” notation confusing.
