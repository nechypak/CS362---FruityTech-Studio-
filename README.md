### "Play. Place. Create." Game-like educational tool

The goal of this project is to make music creation more intuitive and beginner-friendly, with a focus on a game-like interactive approach. Moreover, our aim is to make it accessible by turning it into a sandbox game, where users are able to experiment with different setups, melodies, and loops and utilize more advanced features like simple EQ and sound rolls. \
The system help gamers: 
- Experiment with no music theory
- Prototype beats and loops
- Learn rhythm, common patterns, and structure through enjoyable iterations
